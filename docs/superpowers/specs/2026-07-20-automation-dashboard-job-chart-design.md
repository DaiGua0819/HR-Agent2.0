# 18080 仪表盘岗位环形图与布局优化设计

## 背景

18080 管理员仪表盘已经展示每日处理 KPI 和岗位处理分布，但当前页面存在四个体验问题：顶部 KPI 信息过多、岗位行中的异常数据重复、处理与简历数字偏小，以及桌面端页面无法纵向滚动。管理员还需要把旧 8080 服务中的每日岗位扇形图迁移到 18080，用更直观的方式查看各岗位处理人数占比。

## 目标

- 删除顶部“发送公司信息”和“异常”两张 KPI 卡片。
- 删除岗位处理分布中的“异常”列。
- 放大岗位行中“处理”和“简历”的标签及数值，并保持所有行上下对齐。
- 新增与旧 8080 风格一致的岗位处理人数环形图。
- 仅让仪表盘支持整页纵向滚动，不改变简历库、面试中心等工作台页面的滚动行为。

## 非目标

- 不修改每日统计接口或数据库结构。
- 不新增图表第三方依赖。
- 不改变每日处理明细页和下载简历功能。
- 不修改或重启 8080 服务。

## 数据口径

环形图直接复用 `GET /api/automation-monitoring/daily-summary` 返回的 `byJobPlatform`。

前端先按 `jobType` 汇总 `processedContacts`，因此图表和现有“岗位处理分布”的处理人数口径完全一致。图表自动跟随当前日期、平台、负责人和岗位筛选；筛选变化后由现有摘要请求同时刷新 KPI、岗位列表和环形图，不额外发送接口请求。

同一岗位在多个平台出现时合并为一个扇区。没有选择具体岗位且岗位数超过 8 个时，保留处理人数最多的前 8 个岗位，其余合并为“其他岗位”。总人数是所有可见扇区人数之和。

## 页面结构

顶部 KPI 从 6 张调整为 4 张：

1. 处理联系人
2. 发起求简历
3. 业务简历获取
4. 候选人提问

KPI 下方的监控区域改为双栏布局：左侧为“岗位处理分布”列表，右侧为“岗位处理占比”环形图。宽屏下列表占用更多空间，环形图保持稳定宽度；窄屏下两块内容自动上下排列。

岗位行只保留岗位名称、进度条、“处理”和“简历”两组统计。两组统计使用固定宽度网格列，标签与数字统一放大，避免因数字位数或岗位名称长度导致上下错位。

## 环形图交互

环形图采用旧 8080 的原生 SVG 与 CSS `conic-gradient` 方案：

- 中心显示当前筛选范围内的处理总人数。
- 右侧图例显示颜色、岗位名称、人数和百分比。
- 悬停具体扇区时显示“岗位：N 人，占比 X.X%”。
- 数据刷新后播放约 920ms 的环形绘制动画。
- 支持 `prefers-reduced-motion`，用户选择减少动态效果时取消动画。
- 图表提供包含总人数的 `aria-label`；装饰 SVG 不重复暴露给辅助技术。
- 没有数据时显示灰色空环、中心数字 0 和“暂无可统计数据”。

配色使用旧 8080 的低饱和度多色序列，避免与现有蓝色主色形成单色页面。扇区最多显示 9 种颜色，包括合并后的“其他岗位”。

## 滚动行为

桌面端 `body` 仍保持应用级固定布局，避免影响简历库和面试中心。只为激活的 dashboard 页面建立独立纵向滚动容器，并确保其高度受主内容区域约束。这样顶部导航保持稳定，仪表盘内容可以完整向下滚动，其他页面继续沿用现有内部滚动方式。

移动端继续使用现有整页滚动规则，不创建嵌套滚动冲突。

## 错误与空状态

- 摘要接口失败时沿用现有请求错误处理，不保留与筛选条件不一致的旧图表数据。
- `byJobPlatform` 为空或处理人数全部为 0 时渲染空图状态。
- 非数字和缺失统计值按 0 处理。
- 图例中的超长岗位名称使用单行省略，完整信息仍可通过扇区悬停提示查看。

## 测试与验收

### 前端契约测试

- 页面包含环形图容器、图例和空状态结构。
- KPI 定义不再包含 `sentCompanyInfo` 和 `anomalies`。
- 岗位行渲染不再包含异常统计列。
- 环形图读取 `byJobPlatform` 并按岗位汇总 `processedContacts`。
- 超过 8 个岗位时其余岗位合并为“其他岗位”。
- 图表包含总人数、百分比、悬停提示和减少动画支持。
- dashboard 激活时具备纵向滚动规则，其他工作台页面规则不变。

### 浏览器验证

- 桌面宽屏下 KPI 为四列，岗位列表与环形图左右排列。
- 窄屏下 KPI 和监控区域正确换行，无文字重叠或横向溢出。
- 页面可以从顶部滚动到“最近处理明细”底部。
- “处理 / 简历”在每个岗位行的位置一致、字号清晰。
- 图表中心、图例和提示框数据与岗位列表一致。
- 切换日期、平台、负责人和岗位后，列表与图表同步更新。
- 管理员权限限制保持不变。

## 实现范围

实现将修改：

- `frontend/index.html`：增加环形图语义结构。
- `frontend/app.js`：精简 KPI 和岗位列，增加聚合、扇区、图例与交互渲染。
- `frontend/styles.css`：双栏布局、图表样式、字号调整、响应式和 dashboard 滚动规则。
- `tests/domain/test_frontend_automation_monitoring.py`：补充前端契约断言。

本次不需要修改后端接口。
