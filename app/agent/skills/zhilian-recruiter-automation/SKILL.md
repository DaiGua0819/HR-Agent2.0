# 智联招聘自动化

## 目标

处理招聘端智联会话：进入智联聊天页，筛选未读，识别候选人岗位，复用 `boss_chat_rules.json` 的岗位知识库和筛选规则，完成提问、答疑、求附件简历、跳过不合适候选人，并记录处理结果。主动联系时进入智联推荐人才页，按岗位门槛筛选后只点击“打招呼”，不点击“打电话”。

## Function Call 选择

- 处理智联全部/配置岗位未读消息：`zhilian_process_unread_all_positions`
- 处理当前已打开的智联候选人：`zhilian_process_current_position`
- 只回答当前候选人的最近问题：`zhilian_answer_candidate_questions`
- 当前候选人满足筛选后要附件简历：`zhilian_request_resume`
- 智联推荐人才主动联系/批量打招呼：`zhilian_proactive_contact_recommended_candidates`

## 平台边界

- 智联使用独立 CloakBrowser CDP：`http://127.0.0.1:9226`。
- 智联聊天入口是 `https://rd6.zhaopin.com/app/im`，推荐人才入口是 `https://rd6.zhaopin.com/app/recommend`。
- 智联使用自己的 textarea、联系人列表、职位筛选、未读筛选和“要附件简历”控件，不复用 BOSS/51job DOM selector。
- 业务规则复用 `boss_chat_rules.json`：岗位筛选问题、候选人问答、通过/失败规则、未知问题记录方式都沿用同一份知识库。
- 未配置到知识库的岗位只记录并跳过，不回复、不求简历。已配置的直求简历岗位包括运营 A/B、外部财务产品顾问、AI智能体解决方案负责人等；运营 A/B 在智联不答疑、不筛选，先发送 `你好可以看看简历吗` 或 `你好，方便发一份简历过来吗`，再通过 `directResume` 驱动要附件简历/附件下载。

## 未读消息处理流程

1. 进入智联聊天页后，先切到“未读”，并尽量选择“全部职位”或按用户指定岗位过滤。
2. 从未读列表顶部开始处理真实候选人会话，跳过平台推荐、系统提示、广告引导和非候选人项。
3. 打开候选人后读取候选人姓名、应聘岗位、最近消息、历史状态、是否已经求过附件简历。
4. 根据岗位匹配 `boss_chat_rules.json` 的岗位 section。
5. AI 应用开发相关岗位走基础条件流程：未发送基础条件则发送；候选人明确接受后求附件简历；拒绝或不明确则等待后续或跳过。
6. 销售、HRBP/人力资源、应用技术、电气、国际业务等非 AI 岗位走岗位专属筛选问题和知识库，不发送 AI 岗位常用语。
7. 运营 A/B（企业内容运营负责人（B2B/短视频方向）、B端社交媒体运营）在智联不回答岗位问题、不发送筛选问题；未收到简历且未求过简历时，先发送 `你好可以看看简历吗` 或 `你好，方便发一份简历过来吗`，再执行 `zhilian_request_resume` 要附件简历/附件下载。
8. 财务 AI 团队新增直求简历岗位（外部财务产品顾问/业财智能化顾问/AI财务场景顾问、AI智能体解决方案负责人/AI Solution Architect/AI FDE/AI Workflow Engineer）不发送筛选问题；先用智联专用发送函数发送岗位配置的 `resumeRequestPrompt`，再执行 `zhilian_request_resume` 要附件简历。
9. 候选人提问时先用岗位知识库答疑；知识库没有答案时不回复，只记录为待补充问题。
10. 候选人通过筛选后使用 `zhilian_request_resume`，点击智联页面里的“要附件简历”或等价控件。
11. 发送或求简历后必须观察页面状态和最新消息，记录候选人处理结果、岗位、问题、回复、是否求简历。

## 主动联系推荐人才

1. 使用 `zhilian_proactive_contact_recommended_candidates`，进入智联推荐人才页 `https://rd6.zhaopin.com/app/recommend`。
2. 页面顶部横向显示 6 个岗位；如果目标岗位不在顶部，点击顶部右侧“选择职位”，在右侧职位抽屉中选择目标岗位。右侧抽屉里会显示职位名、账号名和城市，例如“人力资源管培生 宋峰峰 · 湖州”。
3. 必须先确认目标岗位已切换成功，不能在错误岗位下打招呼。
4. 推荐列表每张候选人卡片右侧有“打电话”和“打招呼”。不要直接根据卡片文本就打招呼；必须点击候选人卡片内容区打开简历详情弹窗。
5. 智联详情弹窗是 `.new-shortcut-resume__modal`，关闭按钮是 `.new-shortcut-resume__close`，左右切换是 `.new-shortcut-resume__left/right`。弹窗顶部右侧有“要附件简历 / 打电话 / 打招呼”，只允许点击详情弹窗里的“打招呼”，永远不要点击“打电话”。
6. 打开详情后读取完整简历信息，包括姓名、年龄、学历、求职期望、工作经历、教育经历、专业、岗位关键词和是否已有沟通痕迹。详情文本优先级高于卡片文本。
7. 如果详情或卡片显示已沟通、已联系、已打招呼、继续沟通、沟通过、同事已有沟通记录，直接跳过并关闭详情弹窗。
8. 复用 BOSS/51 主动联系岗位门槛：
   - 应用技术经理：本科及以上、45 岁以下，且有流变助剂、膨润土、工业涂料、涂料研发、涂料工程师任一证据。
   - 销售管培生：至少大专、25 岁以下。
   - 膨润土销售人员：至少大专、35 岁以下，且有涂料、膨润土、流变助剂任一证据。
   - HRBP/人力资源/人力资源管培生：本科及以上、30 岁以下，专业为人力资源/相关专业或理工科。
   - 国际业务管培生：本科及以上、25 岁以下，专业为国际贸易/英语/俄语/翻译，或理工科且英语六级。
   - 电气工程师：本科及以上、35 岁以下，专业为电气工程/自动化，且有 PLC 证据。
9. 学历、年龄、专业、关键词等关键证据缺失时默认跳过，不要猜测。
10. 符合条件后点击详情弹窗顶部的“打招呼”，等待发送结果，再关闭详情弹窗继续下一位。
11. 支持 `dryRun=true` 预览符合条件候选人：仍然打开详情读取完整简历，但不实际打招呼。
12. 已主动联系过、同事已沟通过、状态显示已打招呼的人必须跳过。

## 回复与安全

- 回复要短，不能编造知识库没有的信息。
- 加微信统一不回复；“还要等一段时间”后追问具体多久/具体时间不回复。
- 不绕过登录、验证码、平台风控或权限限制。
- 所有实际点击、输入、发送、求简历动作都走后端 function call，不让模型临场猜 selector。
